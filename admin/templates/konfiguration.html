Von außen erreichbar

Kommen Mitspieler aus dem Internet rein?

Ein großer Teil der deutschen Anschlüsse (Kabel, viele Glasfaseranbieter) hat gar keine eigene öffentliche IPv4-Adresse — DS-Lite. Dort ist eine Portfreigabe im Router wirkungslos, und kein DNS-Dienst der Welt ändert daran etwas. Der Test unten sagt, ob das hier der Fall ist, statt es raten zu lassen.

Dauerhafter Name

Damit niemand Zahlen abtippen muss.

Die meisten Anschlüsse bekommen regelmäßig eine neue Adresse. Ohne einen Namen müssten Mitspieler jedes Mal eine neue Zahl eintippen — und erführen von der Änderung erst, wenn sie nicht mehr hereinkommen. Ein Timer meldet die aktuelle Adresse alle fünf Minuten, aber nur, wenn sie sich geändert hat.

Rot markiert: Der Dienst ist fest an eine Adresse gebunden, die der Router nur verliehen hat (DHCP). Bekommt der Pi beim nächsten Neustart eine andere, kann der Dienst nicht mehr binden und stirbt beim Hochfahren — lautlos, denn bis dahin läuft alles. Abhilfe: entweder auf allen Netzwerkkarten lauschen lassen, oder dem Pi im Router eine feste Adresse zuweisen.

{% endif %}

Dass RCON auf allen Karten lauscht, lässt sich nicht abstellen — einen Schlüssel rcon.ip gibt es nicht. Deshalb muss die Firewall diesen Port sperren. Prüfen mit sudo ufw status. Steht bei einem Port „von einem anderen Benutzer“, gehört er einem Dienst, der nicht dieser Oberfläche gehört (etwa sshd als root): ss nennt den Namen nur dem Eigentümer. Eine sudo-Regel dafür wird bewusst nicht eingerichtet — von Hand geht es mit sudo ss -ltnp.
