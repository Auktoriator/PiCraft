Einschalten und den Server neu starten. Das ist eine Plugin-Datei — sie lässt sich derzeit nur über SSH bearbeiten.

{% elif karte.eigener_port %}

Die Karte steht auf dem Port dieser Oberfläche

In plugins/Pl3xMap/config.yml steht internal-webserver.port: {{ karte.port }}. Diesen Port belegt schon diese Oberfläche, deshalb kann der Kartenserver nicht starten. Im Serverprotokoll steht dazu BindException: Address already in use.

So sieht es aus, wenn ein Pl3xMap-Update die Datei auf seine Vorgaben zurückgesetzt hat. Dann stimmen meist auch bind und web-address nicht mehr. Die drei Werte zurückstellen und den Server neu starten. Hinter einem Webserver (nginx) gehört bind auf 127.0.0.1.
