Zweites Ziel

Eine Kopie auf einem anderen Datenträger.

Eine defekte Platte nimmt alles mit, was auf ihr liegt — egal wie viele Kopien es sind. Ein zweites Ziel auf einem anderen Datenträger (externe Platte, Netzlaufwerk) ist der Unterschied zwischen „mehrere Backups" und „Backups an mehreren Orten". Leer lassen schaltet es ab.

{% endif %}

Geht ein Backup schief, kommt eine Nachricht aufs Handy — und wenn der nächste Lauf wieder klappt, eine Entwarnung. Dafür genügt die App ntfy (Android, iOS) oder ntfy.sh im Browser: Thema abonnieren, denselben Namen hier eintragen, fertig. Kein Konto nötig.

Der Themenname ist das ganze Geheimnis. Bei ntfy gibt es kein Passwort — wer den Namen errät, liest mit und kann selbst Nachrichten schicken. Deshalb kein Name wie „mcs-backup“. {% if not benachrichtigung.an %} Vorschlag: {{ benachrichtigung.vorschlag }} {% endif %}
